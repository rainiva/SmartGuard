# SmartGuard 日志工作台用户说明

日志工作台位于 Settings 的日志页面，用于查看当前日志流、查询历史日志、定位匹配项并导出当前范围的数据。诊断统计位于“关于 → 维护”。

## 常用操作

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 聚焦查询 | `Ctrl+F` / `Ctrl+L` | 将焦点移到关键词输入框。 |
| 下一个匹配 | `F3` / `Enter` | 跳到当前查询的下一个匹配项。 |
| 上一个匹配 | `Shift+F3` / `Shift+Enter` | 跳到当前查询的上一个匹配项。 |
| 导出当前范围 | `Ctrl+E` | 导出当前 query/session 范围，沿用当前脱敏与导出规则。 |
| 当前窗口顶部/底部 | `Home` / `End` | 在当前已加载窗口内移动，不改变历史边界。 |
| 历史起点/终点 | `Ctrl+Home` / `Ctrl+End` | 继续向历史起点或最新终点加载，并移动到对应边界。 |
| 关闭临时层 | `Esc` | 关闭临时面板、关联视图或结束当前临时关联状态。 |

在关键词输入框、密码框或其他文本编辑控件中，`Home`/`End` 保留文本编辑器的原生行为，不会触发日志列表滚动。

## 顶部工具栏与筛选面板

日志页顶部只保留关键词查询、刷新、筛选和导出操作。时间范围、日志级别与会话范围集中在“筛选”浮层中；会话筛选器负责决定“查看哪一段日志”，关键词、级别与时间等查询控件负责决定“在当前范围内匹配什么内容”。

- 默认范围是“全部会话”。此时日志列表、匹配导航和导出按当前关键词、级别与时间范围工作；关键词默认不区分大小写。
- 会话下拉项使用可读标题显示会话；正在运行的会话会标记为活动状态，并可继续接收新增日志。
- 会话元数据尚未准备好时，下拉会显示识别中的状态；没有可用会话时显示空状态；加载失败时显示失败状态。状态项不可作为普通会话选择，失败后重新展开下拉会触发下一次识别重试。
- 下拉高度上限约为 280 DIP，长会话列表在下拉内部滚动；窄到约 600 DIP 的窗口会让顶部控件自然换行，不应遮挡刷新、更多或列表区域。

## 查询、会话与统计

- 保存的筛选器用于复用常用查询；应用筛选器后，日志列表、匹配导航和导出都以同一个查询范围刷新。
- 选择某个会话后，日志范围收窄到该会话边界；关键词、标签、时间、大小写等查询条件仍继续叠加在这个会话范围上。
- 从某个会话切回“全部会话”时，日志页会恢复进入会话前的主视图状态，包括关键词、标签、时间范围、大小写设置、视口锚点和当前选中的日志项。
- 诊断统计位于“关于 → 维护”的折叠区。折叠时不会启动聚合；展开后按日志保留期内的全部日志计算，不继承日志页当前关键词、级别、时间或会话条件，并且只应用最新一轮结果。
- 手工刷新会使已识别的会话元数据失效；下一次展开会话下拉时会重新识别。快速切换 A→B→All 或在查询尚未完成时退出，只保留当前范围的结果，迟到的旧结果不会覆盖新视图。
- 会话视图和“查看本次操作”等关联视图互斥：进入会话会退出关联视图，进入关联视图也会退出会话视图；最终返回主视图时仍回到同一套查询、视口和选择状态。
- 日志级别同时通过文本标签和视觉样式表达，不依赖颜色作为唯一信息来源。

## 刷新、更多与布局

- 顶部手工刷新会重新读取日志并使会话元数据在下次展开时重新识别；刷新不会改变 More 按钮的职责。
- More 按钮继续承载复制、导出、打开文件夹等溢出操作；打开后的浮层仍可通过点击外部或 `Esc` 关闭。
- 在 600 DIP 左右的窄窗口、高 DPI 或键盘操作场景下，顶部会话筛选器、查询控件、刷新和 More 都应保持可达；若需要只用键盘操作，可用 `Tab` 进入会话下拉，`Alt+Down` 展开，方向键移动，`Enter` 选择，`Esc` 取消或关闭临时层。

## 键盘与无障碍

- 可使用 `Tab` 在查询、筛选、列表、统计及操作控件之间移动；焦点位置有可见提示。
- 查询输入框、日志列表、状态区域和日志条目提供控件名称或辅助说明。
- 状态变化通过可读文本呈现，便于辅助技术获取当前加载、匹配和错误状态。
- 高 DPI、高对比度和减少动画环境下，应优先使用上述键盘路径完成操作；发布验收仍以项目清单中的真实桌面验收记录为准。
