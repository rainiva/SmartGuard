## 安装说明

1. 下载 `SmartGuard-Setup-1.0.28-x64.exe`
2. 以管理员身份运行安装程序
3. 安装完成后托盘会自动启动

## 环境要求

- Windows 10/11（x64）
- 安装包已捆绑 .NET 8 桌面运行时，无需单独安装

## 本版本更新

- 设置窗体新增「关于」页，支持检查更新（GitHub Releases）
- 安装包版本号改为从 `installer/version.txt` 读取

- 打包流程迁移至 C#（`SmartGuard.Packaging`），替代原 PowerShell 脚本
