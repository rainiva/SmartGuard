## 更新摘要

本版本自 v1.0.88 以来累积了多项稳定性修复与架构治理改进，**建议所有用户升级**。

### 修复

- **设置 · 显示**：关闭「跟随系统」开关时不再弹出「无法对不可变对象实例进行动画处理」错误
- **安装包**：修复 Inno Setup 脚本中进程停止 helper 的声明顺序，确保安装包可正常编译
- **托盘**：暂停状态改从 `status.json` 读取，菜单显示与引擎实际状态一致
- **恢复逻辑**：状态文件中的引擎 PID 仍存活时，跳过不必要的 `schtasks` 操作
- **LogViewer**：启动后自动跳转到设置窗口的「日志」页（统一入口）
- **启动脚本**：`Start-Core` 改为通过 Guardian 计划任务启动引擎

### 改进

- **设置窗口**：日志页、主题、导航、关于页等模块进一步拆分，界面响应更稳定
- **配置与路径**：默认电源计划 GUID、日志路径等改为单一真源，减少多处不一致
- **架构治理**：完成第三、四轮多真源治理与门禁验收（开发/维护向，不影响普通用户使用）

### 安装

1. 下载 **SmartGuard-Setup-1.0.101-x64.exe**
2. **以管理员身份运行**安装程序
3. 安装完成后会自动注册计划任务并启动引擎与托盘

> 卸载时默认保留配置与日志；可在卸载向导中选择是否一并删除。

### 环境要求

- Windows 10 / 11（64 位）
- 安装包已捆绑 .NET 8 桌面运行时（若系统未安装会自动安装）
