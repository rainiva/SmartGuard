## 更新摘要

修复引擎启动后立即退出、日志中长期只有启动记录而没有心跳与计划切换的问题。建议所有用户升级。

### 修复

- **引擎无法常驻**：安装目录中的 `Microsoft.Win32.SystemEvents.dll` 曾为 NuGet 占位文件，订阅电源事件时崩溃；现已在发布时对齐为 Windows 真实现，并增加安装暂存校验
- **心跳 / 计划切换日志缺失**：引擎进入主循环后恢复正常心跳与计划相关日志；状态文件会持续刷新，设置页不再长期提示「状态可能过期」
- **电源监听兜底**：若系统事件监听仍不可用，改为记录警告并按轮询间隔继续工作，而不再导致进程退出

### 安装

1. 下载 **SmartGuard-Setup-1.4.0-x64.exe**
2. **以管理员身份运行**安装程序
3. 安装完成后会自动注册计划任务并启动引擎与托盘

> 卸载时默认保留配置与日志；可在卸载向导中选择是否一并删除。

### 环境要求

- Windows 10 / 11（64 位）
- 安装包已捆绑 .NET 8 桌面运行时（若系统未安装会自动安装）
